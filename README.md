# 果园管理系统

果园（地块 / 果树 / 采摘批次 / 库存）的台账与采摘入库管理。基于 Spring Boot 3.3 + Vue 3 + MySQL + Redis，docker compose 一键启动。

## 启动

```bash
./start.sh
```

启动后访问 http://127.0.0.1:8241/ 。

## 模块

- 地块：果园分区台账，停用前需清空在管果树
- 果树：果树档案，归属地块、品种、健康状态
- 清树：病弱树开具清树单后置「已清」，可撤回。清树与台账四条对账规则：
  清树成功的同一事务内地块在产株数立刻减一（株数实时按 `status<>'已清'` 统计，不存冗余数）；
  树上还挂着待采/采集中批次时清树被挡住并报出批次号，需先把树从批次摘掉或等入仓；
  已入仓库存不随清树/撤回加减；
  撤回只恢复株数与清前状态，撤单前摘掉的树不自动回挂批次、批次不会因此变回可推；
  同一棵树并发清树，行锁 + 生效单唯一索引保证只留一笔
- 施药记录：按地块登记药名、施药日与安全间隔天数，可作废；停用地块不许补记
- 采摘批次：按地块按日的采摘登记，批次必须挂树，且只可挂本地块在产树（已清树不能进新批次）；
  状态机 待采→采集中→已入仓；
  间隔未满的地块不能新开批次；施药日不晚于批次采摘日且间隔未满的药单会卡住该批次推进，
  解禁或作废后自动放行；已入仓批次挂树冻结、与库存公斤数不受事后补药/清树影响
- 库存：按品种累计产量与出库，低于预警线提示
